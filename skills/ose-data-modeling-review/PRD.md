# 需求文档

PRD（Product Requirements Document，产品需求文档）。

目标：将团队数据手册转为 OSE 专用的数据开发与评审技能。

范围：涉及表结构、查询、业务指标和并发更新时自动选用，覆盖三个现有项目；默认只检查本次新增或修改影响的逻辑，全面审计另行明确。

已确认决策：业务库与数仓字段分开规定；当前允许后端受控查询共用 MySQL，后续逐步隔离；指标在后端统一计算；硬性要求与需要说明理由的设计项分开；示例统一 MySQL；仅 OSE 使用；提问时缩写附完整中英文。

验收：技能格式与引用有效，允许自动选用；规则准确体现上述决策；不强制数仓建设或无关历史整改；示例完整；明确区分静态检查与数据库执行验证。
